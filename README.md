# Arcade

A SNES-*feeling* cabinet for **your** games. Not a Super Nintendo emulator. No Nintendo ROMs, logos, or BIOS.

Loopback: http://127.0.0.1:8933/

You open: Desktop `OPEN ARCADE.bat` (starts the server, does not launch Firefox).

Carts: Dignity Coin Rush, Cyber Town (local PC paths), plus original mini-games in `games/`.

GitHub: https://github.com/Kawhooped/arcade (branch **dd-main**). Mini-games play as static HTML. Dignity/Cyber Town need the local server.
