# Arcade

A SNES-*feeling* cabinet for **your** games. Not a Super Nintendo emulator. No Nintendo ROMs, logos, or BIOS.

Local: http://127.0.0.1:8933/  
You open Desktop `OPEN ARCADE.bat` (does not launch Firefox).

Mini-games live in `games/`. Dignity + Cyber Town load from this PC via `server.py`.

Hub: https://github.com/Kawhooped/farm-board
